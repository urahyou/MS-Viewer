# 现代工作台 v0.2.1

本轮借鉴 CASA PlotMS 的“选择规格—绘图轴—定位”设计，使用现有 Python/PyQt6/casacore 实现；不需要安装完整 CASA。源码参考与固定版本见 [研究记录](research/casa-source-reference.md)。没有移植 CASA 内部 GUI、RPC 或校准算法。

## 用模拟数据走一遍

1. 在“样例”菜单打开模拟 MS。“可见度”保留熟悉的频谱、时间曲线和瀑布图，曲线为当前预览的非加权平均。
2. 切到“观测总览”，先确认天线数、目标、DDID 对应的 SPW 和相关乘积。扫描线段是样本 TIME 的范围，不是积分曝光的起止边缘。模拟数据和校准状态会明确提示。
3. 左侧切到“分组筛选”。列表勾选原始 ID；一项也不勾表示该维度全部。默认第一 DDID 和第一条基线，防止一次加载全部组合。
4. 例如选择一个目标、两个扫描、第一条基线和 XX，点击“读取所选数据组”。上方“当前数据组”逐组切换；每组有自己的 DDID/Field/Scan/基线，不把不同目标平均到一起。
5. 切到“诊断绘图”，X 选频率、Y 选振幅，观察通道变化；X 选时间，观察随时间变化。X=u、Y=v 可查看当前抽样的投影基线覆盖；不是天线地面位置图。切换坐标轴时自动调整该轴范围，另一个轴的缩放保留；“重置视图”同时适配两轴。
6. 点击一个散点，右侧显示原始 MS 行、通道、相关乘积和数值。或开启区域选择，拖动/缩放矩形后点击区域定位。第一个命中点会联动当前组、天线图和可见度光标。点击右侧另一条定位记录，会同步更新详情、相关乘积、当前组和光标，保留原来的整个定位选区。复制按钮输出 CSV，不修改 flag。
7. 修改筛选后旧定位会清空；在分组模式下再次点击读取才应用。切换语言、调整布局或复制参数不会重新读取数据。

诊断图每个点是一个实际预览样本，频谱/时间曲线是预览均值。两者数值不要求相等。例如某个通道只有一个时刻出现窄峰，单点能看到该峰，跨时间的均值可能较低。不能仅凭峰或条纹认定是谱线或干扰，需比较不同目标、基线、时段、校准报告和原始标记。

## 科学标识和单位

- DDID 在 DATA_DESCRIPTION 中关联 SPW 和 POLARIZATION；不假设 DDID=SPW。
- Field/Scan/天线编号、行号和通道号均保留原始 ID，从 0 开始的原始通道不等于缩小后的预览索引。
- 基线保留 ANTENNA1→ANTENNA2 方向；不自动合并反向基线或复共轭。
- XX/YY 等标签来自 POLARIZATION；不把 XX 当作 Stokes I。
- 诊断时间轴相对于所有已载入组中最早有限 TIME，注明日期与时间尺度；筛选时间偏移相对于整个 MS 最早 TIME。详情时间保留 MS 的时间尺度。
- 频率来自 CHAN_FREQ，显示 MHz，没有转换频率参考系。u/v/uv 距离来自 UVW，单位米；缺失或无效时不可用，不能用天线地面距离替代。
- 残差仅接受原始 DATA/CORRECTED_DATA 与 MODEL_DATA 形状和 QuantumUnits 一致的样本；单位未知也会拒绝，避免产生误导的差值。
- 通道下界包含、上界不包含；分组模式上界 0 表示全部。时间和 UV 距离上下界包含；UV 距离是 sqrt(u²+v²)。UV 筛选在抽样之前执行。

## 范围与预算

- 分组查询总计最多 128 组。行数是所有组的总预览预算，每个匹配组至少一行；预算不足会报错要求缩小范围，不悄悄丢弃后面的组。
- 读取沿用 64 MiB 保守预览估算；不代表进程总内存上限。诊断绘图最多显示 100,000 个均匀抽样候选，之后排除隐藏 flag 或非有限值。小组可能未出现在绘图抽样中；状态栏显示覆盖情况。
- Locate 仅命中已显示预览点。详情最多列 200 个记录，同时报告总命中数；不能把它当作全量 MS 导出或全量坏数据筛选。
- 更改坐标轴/flag 显示/数据组会清除旧定位。切轴仅重新适配被改变的轴；同轴手动缩放以及语言/flag 显示切换不会重置另一轴。可用“重置视图”恢复两轴。
- 最近文件、语言、主题和手动保存的布局跨启动保留。各 MS 的筛选在本次运行内恢复；没有完整会话文件、自动路径迁移或 MS 拼接。
- 暂无完整 CASA 表达式、科学加权平均、分页 MAIN/子表浏览、flag 写入、校准与成像。旧 PDF 讲解已有三图与 MS 概念；新增操作以本说明为准。
