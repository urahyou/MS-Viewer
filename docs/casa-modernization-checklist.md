# MS Viewer 现代化改造清单

状态：用户已批准首批 M01/M02/M03/M04 常用轴/M07 原始样本定位，按 v0.2.0 实施。历史基线为 v0.1.2 / `93edabc75c1ae825dc355c34338f223f32fd7506`。其余项目保留为路线图。

## 产品定位与复用方式

建议定位：面向天文学家的现代化 MS 浏览、质量检查与后续处理工作台。

- 保留 Python/PyQt6 桌面交互、中文/英文、离线浏览及独立 Mac 安装包。
- 借鉴 PlotMS 的独立选择、平均、轴、分组、定位、导出模型；用我们的界面呈现。
- 直接读取、轻量可视化继续使用 casacore；校准/成像等科学任务通过可选 CASA 环境的公开接口执行。
- 读取与绘图、草稿标记、真正写盘是三个不同边界。现有 AGENTS.md/spec.md 要求 reader 只读；本草案没有授权改变这个约束。
- 具体源码复制/翻译需记录文件、固定提交、原版权与依赖；模块可用性和许可证事实逐项核对。没有承诺整套 C++/Qt GUI 可直接嵌入 PyQt6。
- CASA 官方新 casagui 的被检查版本仍自称 pre-alpha/prototype；可借鉴边界设计，不把它当作已完成的 PlotMS 替代产品。

源码证据、固定提交、事实与推导的区别见 [CASA 源码调研](research/casa-source-reference.md)。以下表格保留完整路线图；本次具体交付与限制见 [现代工作台使用说明](modern-workbench.md)。

## 本轮建议不纳入首版

- 一次性复制 CASA 所有参数、C++ 控件和内部 RPC；自动全流程校准/自校准；自动得出天体物理结论。
- 全套 CASAviewer/CARTA 级立方体渲染、远程多用户平台、分布式 TB 级计算、全部望远镜/校准表兼容。
- 把 XX/YY 直接当作 Stokes I，或在没有完整定义/验证时合成 Stokes、变换速度轴/频率参考系。

## 开发与验证方式（清单确认后采用）

- 以现有单独模块为起点，将 window.py 中的选择状态、绘图协调、导出/会话和任务协调逐步分开，不做无目标的整体重写。
- 科学参数使用可序列化模型；同一模型供 GUI、缓存键、报告和任务适配器使用。
- 保留真实 casacore 表的 TDD、现有中英文/异步/只读/打包回归；对平均、原始样本映射、单位和 flag 语义增加独立数值对照。
- 和固定版本 CASA 的同一选择/参数对照；不能用平均后的视图截图相似度替代数值验证。
- 每批交付包含测试证据、原生界面 QA 和可安装包；性能承诺以实际数据集、硬件和读取覆盖率的测量为依据。
