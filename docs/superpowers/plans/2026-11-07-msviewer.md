# MS Viewer Implementation Plan

> **For agentic workers:** Implement inline, task-by-task with TDD; review the finished project independently.

**Goal:** Deliver a running read-only PyQt6 MS viewer plus public demonstration data.
**Architecture:** casacore reader returns NumPy data and immutable metadata; pure processing prepares plots; Qt worker jobs keep UI responsive.
**Tech Stack:** Python 3.12, PyQt6, python-casacore, PyQtGraph, NumPy, Astropy, pytest-qt.
**Spec:** docs/spec.md

## Global Constraints
- Python 3.11+; read-only MS v2 access.
- Bounded previews, truthful axes, respect FLAG and FLAG_ROW.
- TDD RED→GREEN for each component; real casacore fixtures and Qt integration.

## Review Focus
- Empty selections / missing DATA / FLOAT_DATA-only datasets.
- Multiple DDIDs with different shapes and non-identical SPW ids.
- Fully flagged values / phase wrap / nonfinite data.
- Rapid UI selection changes / errors / closing during reads.
- Large row/channel selections and invalid bounds.
